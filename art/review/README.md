# ART-01 — D2 sprite prototype
Review only: manually specified original raster pixel shapes, no downloaded client art, no image generation. Style target is user reference (HD Pixel Chibi anime); these are a first low-detail approximation, NOT final production quality. PNG preview shows Naruto, Sasuke, Kakashi, Itachi left to right. Transparent walk key sheet 256x320: rows in same order, 4 columns of 64x80 cells; frame anchors (32,73), front/three-quarter only, frame cadence proposed 8 fps. Key poses contain discrete arm/leg/head shifts; two middle neutral poses may repeat. These are not completed animations (no directions, attack, cast, hit, death, sprite VFX). Static isometric mockup demonstrates approximate on-map scale and two tiny chakra VFX placeholders. No Godot runtime test, no exact-match claim, no production gate passed. The user image remains private and is not copied into the public repository. No proprietary asset redistributed. Need owner approval and full sprite art refinement before batch.
