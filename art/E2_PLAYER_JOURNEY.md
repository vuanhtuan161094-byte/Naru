# E2 Player journey
New primary dashboard with three tabs: Next, Growth, Quests. Reads current save, chooses actual next campaign stage and shows cost/reward, empty team, stamina shortage and real 360s recovery. Provides action routes to recruitment, formation, village, training, breakthrough, stars, skill prerequisites, resource guide and actual quest claims. Uses existing state gates, no fake rewards, no spend on suggestion. Opening default is Journey except existing web QA path. Growth recommendations are heuristic, not a simulated win predictor. Existing gameplay unlocks unchanged. Daily quests normalized on a copy; actual claim via original transaction. Manual refresh or reentry recomputes state. No new art. E1 smoke remains required.
