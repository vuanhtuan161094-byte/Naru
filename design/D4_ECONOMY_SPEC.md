# D4-A — Kinh tế, tăng trưởng và chiêu mộ
D4 recruitment.json overrides D3 initial_quality for recruitment and initial character quality. D3 had four empty tiers; all eight are now populated with proposed rarity assignment. User locked eight initial ranks, not individual rarity. All currencies are in-game, no monetization. Duplicate grant is atomic. Pity counters independent; guarantee resets only if tier threshold met. A version is separately ownable but same identity per active team is a proposed restriction, not approved.
Initial save seed and direct supply provide candidate starting stocks and buildings; do not interpret period seconds as passive grants for all reward-based sources. Mission/boss/trial resources only awarded on a qualifying event; production building sources only when unlocked, assigned and stock available. Supply classes are not a proof of full economy reachability; source-level schedules require runtime testing. Upkeep zero, no daily login penalty. Upgrade costs and duration in balance_rules.json; no spending until inputs validated. Auto-production reserves inputs atomically, pauses on shortage, resumes when possible, and respects storage capacity. Proposed warehouse capacity per resource 10000+5000*level (currency exempt). Building damage reduces production until repair; repair cost ceil(base_ryo*(1-condition)*level), minimum condition .5, no loss of level.
Growth steps preserve eight qualities, 15 stars, infinite realm progression, costs and pity. Store points as nonnegative values; use safe numeric representation and display compact numbers. If numerical precision becomes insufficient, switch to explicit mantissa/exponent or arbitrary precision design, not an artificial progression cap. No quality regression. Talent fixed + random first acquisition. D4 gear defines set eligibility, upgrade/refine/evolve/reroll/socket. Set bonus applied at highest attained threshold only; do not sum all three. Gear quality capped 8 but upgrades remain unbounded. Bloodline implantation is a sandbox-only proposed mechanic; compatibility and exact ocular prerequisites still need individual review. Boss phases contain concrete skill IDs and modifiers, not fully unique mechanics. All numerical seeds are proposals and tested only through basic numerical sanity checks, not gameplay simulation.
