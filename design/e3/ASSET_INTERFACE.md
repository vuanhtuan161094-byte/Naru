# E3 Asset contract v1 (proposed)
Renderer loads asset registry by stable ID; no gameplay depends on artwork. Character lookup NIN-###, form NIN-###-F#, VFX key VFX-NIN-###-S#, portrait/skill icon same IDs. Original art test identities ART-R3-001..004 are STYLE_TEST, not mapped to actual Naruto characters without owner approval. Missing asset falls back to visibly DEV placeholder; do not make mockup final.
PNG RGBA, no background/shadow baked into character; nearest-neighbor, pixel crisp. Candidate cell 96x112, anchor foot center per clip; frame rectangles and duration_ms explicit; directions NE/NW/SE/SW; actions idle/walk/attack/cast/hit/fall; frame-by-frame, no rig. Proposed counts 6/8/8/10/4/6 (168 cells/character); validate each animation visually, no repeated stills as completed walk. Use asset metadata schema fields id, kind, source, approval, cell, anchor, clips, frames [{rect,duration_ms}], direction, action. Static artwork may use single pose and no animation clip; must not claim ready.
VFX source separate charge/travel/impact/residual layers, effect origin/target attachment, no full-screen glow; pixel primary, Godot glow/particles secondary. Preserve foot anchor and hit timing, no equipment sprite swaps. Runtime registry supports review, approved and DEV fallback, only approved final. Source ledger includes generation provenance and rights status. No user reference image or commercial asset committed to public repo.

## Combat V3
Use runtime map_width/map_height and iso(p) projection. Never hardcode 12×8; effects use world positions, deployment_slot is initial metadata only. No raster review in place of actual gameplay.
