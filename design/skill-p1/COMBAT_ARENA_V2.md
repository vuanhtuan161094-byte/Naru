## Proposed hybrid arena
12x8 logical meters, 1m tiles; tile grid is collision/pathing/terrain, not turns. Each side front/back rows of three, x coordinates 3/1.5 vs 9/10.5 and y 2/4/6. Continuous movements at 20Hz. Bodies have radius; safe spawn, no overlap, no out-of-bounds. 0.35m ninja, 0.25m clone, 0.65m boss provisional. Ground axes independent of isometric camera. Dynamic walls must update navigation; line-of-sight and projectile walls use same geometry. Pathfinding on grid then continuous path following/local avoidance; no teleport without valid landing. Ranged/support maintain distance, front line intercepts, assassins flank. Role not a hard restriction on starting slots. 
## Cast contract
Cast start -> windup -> release -> travel/contact -> impact -> recovery -> residual. Target UID lock for targeted spells; ground point lock for ground AoE; projectile launch snapshot origin/direction, swept collision to impact; homing only declared. Hit/miss event after resolution; render confirmed hit not merely release. Telegraph for large/manual spells; normal skills AI, manual ultimate AI chooses point with deterministic tie break. No friendly fire by default. Shape library and parameters in arena_contract.json. All targeting uses body circles and geometry; per cast target cap and hit_index dedup. Coefficients total across hits, not per hit. Zones expire and have explicit tick intervals, elemental reactions one per pair, no infinite loops.
