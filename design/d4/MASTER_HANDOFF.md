## Module boundaries
- DataRegistry: parse JSON, reject duplicate IDs, schema/refs and version checks, immutable definitions. D4 overlays by explicit ID. Fail actionable; do not silently drop records.
- SaveService: schema version, save seed, last committed timestamp, inventory, instances, training, skills, gear, teams, jobs, timers, quest counters, world, event ledger; atomic temporary write + recovery backup; migration with no reset.
- TransactionService: validate all costs then atomic debit/grant; deterministic idempotency key; no negative inventory, no double reward.
- GrowthService, SkillService, EquipmentService, RecruitService: typed formulas, pity scoped by instance/target, preserve investments.
- CombatSimulation: pure deterministic 20Hz, AI utility, range/pathfinding, effect dispatch and status system, reaction lock, manual ultimate commands, battle results. CombatScene only presentation and input, no duplicate state mutation.
- VillageService, CraftService, JobService: fixed lots, upgrade queue, input reservation, production pause/resume, job survives battle.
- WorldSimulation, DiplomacyService, TravelService: deterministic ticks, stock/capture/trade/raid/defense; offline cap 24h and anti-repeat; story independent.
- CampaignService, QuestService, BeastService, ComboService: authored data with explicit unlock/rewards.
- UI navigation stack: 17 screen contracts, back/close, localization Vietnamese, portrait action bars, multi-ultimate overflow with no lost skill access.
- AssetRegistry: atlas/metadata/anchors, 4 diagonal directions, sprite frame-by-frame only, no equipment sprite swap. VFX startup/travel/hit/fade. Placeholders must carry visible DEV flag until art gate passes.
