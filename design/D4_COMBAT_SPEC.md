# D4-A — Hợp đồng chiến đấu V1.1 (đề xuất triển khai)
D4 files overlay D3 skill IDs; preserve names, unlocks, provenance, and progression. Use data/d4/skill_contracts.json for effect payload, target, costs, shape and timing rather than D2/D3 fields. D4 contracts are first-pass deterministic classification by skill names/effects, not individual canon validation or runtime balancing. No unrelated learnable jutsu. All unlocked auto skills compete by AI; all unlocked ultimates have separate manual buttons. AI never casts ultimate automatically by default.
Combat 20 Hz, integer tick clock, stable actor ID ordering, seeded RNG. Reserve resources at cast start; on interrupt before release refund 80% chakra, apply half cooldown (proposal). Release event checks target alive, no retarget for projectile; after release no refund. Movement uses continuous world plane with isometric projection, obstacle collision, y-sort by feet. Resolve hit→penetration→crit→element→realm→damage reduction→shield→HP. For genjutsu use genjutsu_power and genjutsu_resist, no physical crit; control probability is base_chance*(1-control_resist_effect), clamp 0..0.95; target with hard CC immunity ignores new hard CC. On hard CC expiration grant 2s immunity; debuff ticks never recursively create reactions. Status duration in ticks, poison/burn deal caster NATK*coefficient per second; maximum stack per source as catalog. Shield refresh max, no additive same caster. Dodge and accuracy use rating difference. All percent effects soft capped, raw points unbounded. Death cancels cast, removes summons. End when one team defeated; no timer; deadlock warning and optional withdraw after 120s no progress. Full heal after battle. Permanent action ledger ignores friendly damage, trivial foes, overheal, idle loops; apply once on result.
Form contracts include proposed manual stance or skill triggers, no skill removal; if locked, AI skips transform. For a manual activation, pay form cost once; skill-triggered activation pays skill cost only. No stacking forms on same ninja. Empowered skill coefficients are temporary. Summon entities are bounded and cannot recursively summon. Environmental and affinity rules are design-specific, not canon claims. Reaction multipliers apply once on overlapping cast pair; secondary effects cannot trigger further reaction. Explicitly decide animation bindings after art approval.
Remaining work: verify every named skill against original era; hand-tune every contract, including ambiguous targets and unique mechanics (Izanagi, Karma, ocular powers etc.). D4 numerical contracts are proposed not locked by owner.
